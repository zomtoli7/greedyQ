Google Sites의 기존 임베드 교체

기존 화면을 유지하며 Prolific 독립 페이지, 앞뒤 안내, 버전·업데이트 이력을 반영합니다. 아래 버튼은 코드만 복사하며 Google Sites를 자동 수정하거나 게시하지 않습니다.

코드를 준비하고 있습니다.

  1. Google Sites 편집 화면에서 기존 사이트 임베드를 선택하고 연필 모양의 편집 버튼을 누릅니다.
  2. HTML 코드 전체를 선택해 복사한 코드로 교체합니다.
  3. 임베드를 저장하고 Guide → Collect의 배포와 수집 → Prolific 연결하기 → 응답 확인, 언어 전환, About의 버전·이력을 확인합니다.
  4. 공개할 준비가 되면 Google Sites의 Publish로 반영합니다. 도메인·공유 설정을 바꿀 필요는 없습니다.
직접 선택해서 복사하기

실제 응답·비공개 결과·완료 코드·인증정보를 사이트에 넣지 않습니다. 유료 Prolific 제출·지급 검증은 내부 검토 대기 중입니다.
