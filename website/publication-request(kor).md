HTML은 정확히 **763948바이트**, SHA-256 **`d13329ce9a5cf84428967492e3eff73acb95a7978604e9df55d0480cc1327773`**입니다. 소스 커밋은 주요 구현을 가리키므로 그 커밋의 옛 HTML만 가져오지 말고 현재 메타데이터 커밋까지 받으세요.

## 브라우저 기능이 있는 홈페이지 워크에 전달할 요청

소유자가 승인한 기존 greedyQ Google Sites 편집 화면을 여세요. 사이트·도메인·페이지·탐색·갤러리·이미지·연락처와 다른 수정은 보존합니다. 기존 전체 화면 사용자 코드 삽입 영역 하나만 준비된 HTML 전체로 바꾸고 저장·게시하세요. 이 승인은 홈페이지 내용에 한하며 설문·결과 배포, 데이터베이스, 응답 기록, Prolific, 지급·모집을 바꾸지 않습니다.

영어·한국어·중국어를 휴대폰·컴퓨터 폭에서 확인하세요. 시작하기의 설명 문단 다음, 복사 요청 앞에 지원 안내가 있어야 합니다. 소개 > 호환성에는 **이용 가능한 AI 에이전트**(`about/agents`)가 있어야 합니다. 필요한 기능이 있는 설치된 ChatGPT·Claude 데스크톱만 현재 지원하고 Gemini는 향후 지원 검토, Meta AI·Grok·DeepSeek는 추가 검토 후보입니다. AI 웹 앱 등 미지원 환경은 제작을 멈추며 앱이 불분명하면 먼저 확인합니다. 확인되지 않은 Google의 GitHub 차단 정책을 원인으로 단정하지 마세요. 참여자는 계속 브라우저로 응답합니다.

버전과 업데이트 히스토리에 `0.2_2026-10-26_e3958de`가 표시되어야 합니다. CBC는 **v0.3 개발 기능**이며 v0.2 완료 기능이 아닙니다. 연락처는 `greedyq.contact@gmail.com`입니다. 연구자용 결과 접근 안내, 유료 시험의 검증 한계, OSF 초안 파일만 제공하는 절차를 보존합니다. 복사 버튼·수동 복사를 시험하고 줄바꿈이 없어져도 URL이 분리되며 BibTeX 코드가 변하지 않는지 확인하세요.

공개 페이지의 `data-code` 전체를 해독해 manifest의 바이트 수·SHA-256과 정확히 대조하세요. 편집 저장이나 기존 공개 페이지가 이번 버전의 게시를 뜻하지는 않습니다. 실제 확인 뒤에만 게시 상태·방법·릴리스·일치 해시를 기록합니다. 권한·도구가 없으면 게시 대기로 보고하며 성공했다고 바꾸지 마세요.

## 현재 확인한 상태

이번에 준비한 HTML은 이 워크에서 Google Sites에 게시하거나 공개 페이지와 대조하지 않았습니다. manifest의 이전 게시 증거는 그 기록에 명시된 과거 버전에만 적용됩니다. 브라우저 기능이 있는 홈페이지 워크에서 현재 HTML을 게시한 뒤 위 바이트 수·해시와 대조해야 합니다.


새 연구와 전달받은 연구 폴더·ZIP 재개 모두 시작 주소는 https://greedyq.netlify.app/로 통일합니다. INITIALIZE.md와 GUIDE-ACCESS.md는 GitHub에 유지합니다. 2026년 10월 26일 연구자가 Gemini의 공개 페이지 읽기를 확인했으며 이는 사용자 확인 결과일 뿐 공식 제작 지원을 뜻하지 않습니다. 현재 준비된 HTML을 게시하고 정확한 해시를 대조해야 하며 과거 게시 증거를 재사용하지 않습니다.
