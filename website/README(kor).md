# Google Sites 웹사이트 원본

[English](./README.md)

2026-10-25에 소유자의 공개 Google Sites 임베드에서 가져온 렌더러·갤러리·이미지를 보존합니다. `content.json`은 기존 영어·한국어·중국어 간체 내용이며 `prolific-content.json`은 독립 Collect 페이지와 앞뒤 페이지 수정 내용을 담습니다. 템플릿은 기존 앱이며 호스팅 서비스를 바꾸는 작업이 아닙니다.

`python3 tools/build_website_embed.py`를 실행하면 `release.json`과 영문·한국어 업데이트 노트를 읽어 `google-sites-embed.html`을 생성합니다. 하단 표시·About → 버전과 업데이트·이력 링크가 같은 현재 식별자를 사용합니다. 실제 설문·비공개 결과·인증정보·참여자 ID·운영 스냅샷은 임베드하지 않습니다.

## 기존 Google Site에 반영

1. 소유자의 Google Sites 편집 화면에서 기존 전체 페이지 커스텀 임베드를 선택합니다.
2. 편집/연필과 HTML 코드 편집을 선택합니다. 기존 페이지·권한·도메인 포워딩·레이아웃은 유지합니다.
3. 코드를 `google-sites-embed.html` 전체 내용으로 교체하고 미리 확인한 뒤 임베드를 저장합니다.
4. Guide → Collect의 배포와 수집 → Prolific 연결하기 → 응답 확인 순서를 검사합니다. 영어·한국어·중국어, 이전/다음, 모바일 메뉴, 프롬프트 복사, About → 버전과 업데이트를 확인합니다.
5. 초안 편집·저장은 공개 게시가 아닙니다. Publish 전에는 소유자의 게시 결정과 해당 브라우저 도구의 권한 규칙을 따릅니다. 게시 후 공개 사이트를 확인하며 파일 생성만으로 실제 웹사이트가 변경됐다고 주장하지 않습니다.

소유자가 `/p/1f5xyMm0_Og8HeJkxgVDcRC8tJC2GTsQO/edit`로 끝나는 편집 페이지를 제공했습니다. 2026-10-25에 소유자가 macOS 손쉬운 사용 권한을 허용하고 Safari에서 직접 업데이트를 요청한 뒤, 기존 임베드를 Safari에서 교체·저장·게시했습니다. 공개 사이트에서 `data-code` 임베드를 별도로 가져와 해석한 결과 `google-sites-embed.html` 전체와 정확히 일치했고, `0.2_2026-10-25_0af2387` 및 독립 Prolific 안내 페이지를 포함했습니다. 이는 이번 게시에 대한 확인이며 이후 수정은 다시 검증해야 합니다. TinyFish는 사용하지 않았습니다.

이후 초보 연구자 점검 버전 `0.2_2026-10-25_7beafe4`도 2026-10-25에 Safari에서 저장·게시했습니다. 공개 페이지를 별도로 가져와 생성 임베드 전체와 정확히 일치함을 다시 확인했습니다(SHA-256 `37c382b094e3ec977600a3b7f09c7fdbed64b8eb51dd85b8bffdbed989e51614`). 유료 시험의 설문·결과 배포는 변경하지 않았습니다.

Claude 시험 후속 조치와 AI 협업 배정 안내 릴리스 `0.2_2026-10-25_15d4d3e`도 2026-10-25 Safari에서 저장·게시했습니다. 공개 사이트의 전체 임베드 687739바이트가 생성 원본과 정확히 일치했습니다(SHA-256 `a774a5a2c8544d4b56d04a2b879f9d822b4ad4a8c0bb6d1e2faea3754d1bef44`). 가이드에는 Vercel 연결 준비와 4개 그룹·그룹별 순차 자극물 예시가 포함됩니다. 버전 갱신 후 Python 187개와 Node/브라우저 41개 시험이 모두 통과했고 건너뛴 시험은 없습니다. Vercel/Supabase 배포 및 유료 Prolific 시험은 변경하지 않았습니다.

## 현재 게시 작업 전달

최신 홈페이지 파일은 [게시 요청문](./publication-request(kor).md)과 생성된 `publication-manifest.json`을 함께 사용합니다. manifest에 버전·바이트 수·SHA-256을 기록합니다. 홈페이지 업데이트 Work가 별도로 저장·게시·공개 페이지 대조를 해야 하며 소스 갱신만으로 게시를 주장하지 않습니다. 현재 Prolific 안내는 기본 유료 시험 완료, 연구자의 승인·지급 확인, 남은 검증을 구분합니다.
