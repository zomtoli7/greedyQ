# 연구자 커뮤니케이션 계약

[English](./communication.md)

기본 사용자는 소프트웨어 지식이 전혀 없을 수 있는 연구자입니다.

## 구현 세부사항 대신 이렇게 말하기

- “Schema validation을 통과했습니다” 대신 “설문 구조를 확인했습니다”라고 말합니다.
- “Route graph에 unreachable terminal이 있습니다” 대신 “참여자가 완료 페이지까지 갈 수 없습니다”라고 말합니다.
- “Unresolved decision이 생성을 막습니다” 대신 “참여 자격에 대한 결정이 아직 필요합니다”라고 말합니다.
- “Artifact hash가 일치하지 않습니다” 대신 “설문이 바뀌어 사전등록 초안을 갱신해야 합니다”라고 말합니다.
- “Deployment verification이 pending입니다” 대신 “실제 설문 링크는 아직 시험하지 않았습니다”라고 말합니다.

연구자의 결정에 도움이 될 때는 연구 용어를 사용합니다. 낯선 용어는 짧게 설명합니다. 요청받았거나 실패를 설명하는 데 꼭 필요한 경우가 아니면 내부 파일 목록, hash, schema name, validation code, deployment mechanics를 노출하지 않습니다.

작업을 마칠 때는 지금 검토할 수 있는 것, 아직 필요한 결정, 안전한 조사 시작을 막는 사항, 추천하는 다음 행동 하나만 보고합니다. 상세 기술 증거는 내부 validation report에 둡니다.
