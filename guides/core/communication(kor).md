## 참가자용 언어 확인

참가자용 내용을 작성하기 전에 어떤 언어로 보여줄지 묻습니다. 연구자와의 대화 언어는 별도로 유지합니다. 중국어라면 간체(`zh-CN`)인지 번체(`zh-TW`)인지 확인하고 대화 언어로 추정하지 않습니다. 확정한 언어를 QMD의 `greedyq.language`에 기록합니다. 기본 참가자 화면 문구는 현재 `en`, `ko`, `zh-CN`, `zh-TW`를 지원합니다. 미지원 언어는 영어로 조용히 대체하지 말고 설명합니다.

제목, 필요한 경우 연구팀명, 페이지, 동의서, 문항, 선택지, 검증 안내, 커스텀 안내, 버튼, 이미지 설명, 미디어 대본·자막, 종료·반환 문구를 모두 번역하고 연구자에게 검토받습니다. 언어 설정만 바꿔서는 이 원문들이 번역되지 않습니다. ID·저장 값·조건·URL·응답 데이터는 번역하지 않습니다. 언어 변경 시 연구 설계를 바꾸지 말고 번역을 명시적으로 검토받습니다. 정상 페이지뿐 아니라 미응답·잘못된 입력·로딩/실패·완료·참여 거부 화면도 검사합니다. 브라우저가 제공하는 날짜 선택창·미디어 메뉴는 브라우저/OS 언어를 따르므로 설문 언어로 바뀐다고 약속하지 않습니다. 연구자용 미리보기 도구와 결과 대시보드는 별도 인터페이스 언어 범위입니다.

## 구현 세부사항 대신 이렇게 말하기

- “Schema validation을 통과했습니다” 대신 “설문 구조를 확인했습니다”라고 말합니다.
- “Route graph에 unreachable terminal이 있습니다” 대신 “참여자가 완료 페이지까지 갈 수 없습니다”라고 말합니다.
- “Unresolved decision이 생성을 막습니다” 대신 “참여 자격에 대한 결정이 아직 필요합니다”라고 말합니다.
- “Artifact hash가 일치하지 않습니다” 대신 “설문이 바뀌어 사전등록 초안을 갱신해야 합니다”라고 말합니다.
- “Deployment verification이 pending입니다” 대신 “실제 설문 링크는 아직 시험하지 않았습니다”라고 말합니다.

연구자의 결정에 도움이 될 때는 연구 용어를 사용합니다. 낯선 용어는 짧게 설명합니다. 요청받았거나 실패를 설명하는 데 꼭 필요한 경우가 아니면 내부 파일 목록, hash, schema name, validation code, deployment mechanics를 노출하지 않습니다.

작업을 마칠 때는 지금 검토할 수 있는 것, 아직 필요한 결정, 안전한 조사 시작을 막는 사항, 추천하는 다음 행동 하나만 보고합니다. 상세 기술 증거는 내부 validation report에 둡니다.
