# CBC 기능 모듈 — v0.3

[English](./guide.md) · [简体中文](./guide(zh-CN).md)

CBC는 일반 greedyQ 설문에 삽입하는 모듈이며 별도 설문 유형이 아닙니다. 기존 일반 문항은 survey.qmd에 유지합니다. 연구자가 “여기에 CBC 태스크를 넣어줘”라고 하면 해당 위치에 모듈 페이지 하나를 추가합니다. 앞뒤 일반 문항은 기존 고정 파서·렌더러로 진행합니다. 연구자에게 사전/사후 설문을 따로 만들거나 내부 before/after 배열을 배우도록 요구하지 않습니다.

AI와 설계하기, 빈 CSV/XLSX 채워오기, 기존 설계 가져오기 중 무엇을 원하는지 묻습니다. 선택을 기록하고 속성·수준·대안·과제·블록·선택하지 않음·표시 순서를 확인받습니다. 방법론적 승인 내용을 임의로 만들지 않습니다. 빈 표를 전달할 때 필요한 파일과 다음 질문을 남기고, 돌아오면 고정 버전을 보존합니다.

첫 혼합 모듈 규약은 선형 설문에 CBC 시퀀스 하나를 지원합니다. 모듈을 별도 페이지에 두고 필요하면 삽입 위치에서 페이지를 나눕니다. 복수 CBC 시퀀스, 모듈을 가로지르는 페이지 분기, 별도 실험 무작위 배정을 몰래 흉내 내지 말고 설계 변경 전에 한계를 설명합니다. 문항별 조건 표시와 기존 지원 컨트롤은 계속 사용할 수 있습니다.

```r
sd_cbc(name = "course_choices", design = "study.design.json")
```

소스만 담은 제작 파일 전달·재개·복제·명시적 버전 업그레이드는 greedyq/cbc_authoring.py를, 일반 QMD 문항과 모듈의 연결은 greedyq/cbc_flow.py를 사용합니다. collection.json에는 동의문과 명시적인 배포·모집 승인을 별도로 기록하며 두 번째 설문지가 아닙니다. 고정 수집 렌더러·추가 마이그레이션 010_cbc_module.sql·보호된 CBC RPC가 순서·저장 확인·완료·철회를 처리합니다. 대체 HTML이나 일반 v0.2 저장 경로로 모듈 세션을 구현하지 않습니다.

일반 build가 sd_cbc를 감지하여 통합 컴퓨터·모바일 미리보기와 비공개 준비 묶음을 만듭니다. 네이티브 surveydown CBC 내보내기는 명시적 미지원이며 모듈을 지워 완성된 것처럼 내보내지 않습니다. 실제 모집에는 승인된 참여 안내·연구팀 연락처·자료 계획·모집 결정이 필요합니다. 로컬·클라우드 가상 시험이 그 승인을 대신하지 않습니다.
