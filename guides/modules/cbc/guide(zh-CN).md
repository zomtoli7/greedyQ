# CBC 功能模块 — v0.3

[English](./guide.md) · [한국어](./guide(kor).md)

CBC 是插入普通 greedyQ 问卷的模块，而非独立问卷类型。普通问题继续写在 survey.qmd；研究者提出“在这里加入 CBC 任务”时，在该处添加模块页。前后问题继续使用固定解析器和渲染器，无需另建前测／后测问卷或学习内部 before/after 数组。

先确认 AI 协作设计、填写空白 CSV/XLSX，或导入已有设计。保存选择，再确认属性、水平、替代项、任务、区组、不选择及顺序；不得编造方法或批准。交付空白表时保存所需文件及下个问题，恢复时保留锁定版本。

首个混合模块规范支持线性问卷中的一个 CBC 序列。模块独占一页，必要时在插入处拆页。多个序列、跨模块页面分支或独立实验随机分配不能默默近似实现；改变设计前说明边界。题目条件显示及已有控件继续可用。

```r
sd_cbc(name = "course_choices", design = "study.design.json")
```

使用 greedyq/cbc_authoring.py 处理仅源文件的交接、恢复、复制及明确批准的升级；使用 greedyq/cbc_flow.py 编译普通 QMD 页面与 CBC 模块。collection.json 保存同意及部署／招募批准，并非第二份问卷。固定渲染器、追加迁移 010_cbc_module.sql 与受保护 RPC 处理顺序、保存确认、完成和退出。不得自行重写 HTML 或绕过模块使用 v0.2 写入接口。

普通 build 会识别 sd_cbc 并生成集成电脑／手机预览与私有准备包。原生 surveydown CBC 导出仍明确不受支持，不得删除模块后声称已完整导出。真实招募仍需研究说明、团队联系、数据计划与明确批准；虚拟测试不构成批准。
