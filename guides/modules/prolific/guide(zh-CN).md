# Prolific 模块

[English](./guide.md) · [한국어](./guide(kor).md)

确认参与者、研究、会话的 URL 参数，何时允许保存，防重复规则，以及完成、筛除、拒绝同意和退出各自的返回地址。不得编造完成码或实际返回地址。

遵循 [Prolific 设置](../../../PROLIFIC-SETUP.md)，使用 `tools/prepare_prolific.py` 准备离线字段。请研究者创建或登录研究者账户，选择工作区，建立带 URL 参数的草稿，并提供真实研究 ID 与各结束路径。将真实审阅记录写入 `respondents.prolific`，不要为通过检查而虚填确认。普通 ID 不是签名验证；本模块不支持签名 URL 或正式重复提交。连接试验不能暗中启动招募或付款。

依次应用 001–004 后的 005–006，注册已审阅模型；普通连接启动使用原子操作 `greedyq_start_prolific`。保留已应用的迁移。返回或显示码之前，退出须原子删除回答、分配、同意事件和浏览器回答/顺序状态，只保留已告知的最少管理标识，用于返回及防重复。不要声称此次升级删除了旧退出记录或已有下载。测试刷新、退出后写入拒绝、同时写入、结果/CSV 无回答及其他记录完好。原生 surveydown 导出须说明删除行为的差异。

重复草稿 Preview 使用受保护结果页签发的 24 小时权限及 `greedyq_start_prolific_preview`。`gq_preview` 是私密测试权限，不是模式开关。数据库验证后，用原 Prolific ID 开始新的测试尝试。使用默认“Start a new test”，不要换研究 ID、编造参与者 ID、删回答或关闭正式防重复。刷新恢复原尝试，重新测试保留先前尝试。正式模式、过期、缺失和错误研究的权限均须被拒绝。签发 API 必须受整个项目的 Vercel Authentication 保护。

测试同浏览器恢复、并发防重复、测试/正式分离、先保存后返回，以及 CSV 的 ID 连接。受保护导出含三项 ID，不需要公开结果。明确证据来自模拟、草稿 Preview 还是真实提交。区分 Prolific 已有预筛条件和自定义筛选，后者须审阅筛除报酬。不得编造码或把“请求返回”视为已完成返回。

按同意与数据计划收集所需标识，避免不必要显示。离线预览禁止真实跳转；获批准的 Test 草稿试验可以走已审阅返回路径。实际外部配置与全程验证须获明确批准并核对结果。

将平台审查/暂停状态与问卷模式、部署状态和回答状态分开。收到“无需行动”的常规审查通知时保留设置、码及预算并等待；不要重复创建、充值、切换模式或反复发布。用离线 `tools/prolific_status.cjs` 汇总受保护结果快照与明确平台证据。仅有数据库回答不证明有付费提交或付款。付费试验须确认人数、真实时长、报酬、显示总额、审核方式及真正参与者使用的任务和同意说明，不能让参与者操作模拟结束选择器或假装拒绝/退出。正式 URL 的 Prolific Preview 可能生成 Real 记录；模拟使用单独 Test 模型。确认回答、管理 ID 及下载的删除期限和执行者，不暗示已有自动定期删除。

迁移 007 仅在接受新的完整回答快照时删除该会话已移除的回答。条件题隐藏并清除后，后续结果和 CSV 也须移除。不会批量改写其他会话或旧记录。已有安装须按审阅的升级流程补上 007；本地源码变更不会自动更新已有正式研究。

## 如实结束付费试验

分别记录保存/CSV 检查、平台提交匹配、研究者批准和付款，并写明日期及证据来源。研究者明确确认可作为批准/付款依据，但不能声称已独立读取 API 或交易收据。保留带日期的旧记录，并链接最新状态；完成标记或已保存回答本身不证明付款。[项目的一人付费试验](../../../docs/prolific-paid-test-completion-2026-10-26.md)按此区分于 2026-10-26 完成，并不认证每个账户或研究。迁移 008 后的首份真实结束时间、付费内部筛选、未支持的签名/API 自动化和保留期限清理要单列。按顺序应用基本迁移至 008，首次结束时间由服务器记录且重试保留；历史空值不回填。试验完成不授权再次付款或招募。
