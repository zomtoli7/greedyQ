# Prolific Module

[English](./guide.md)

어떤 URL parameter가 participant, study, session을 식별하는지, 언제 저장할 수 있는지, 중복 참여 처리, 완료·선별 탈락·동의 거부·철회의 각 destination을 확인합니다. Completion code나 실제 return URL을 지어내지 않습니다.

필수 identifier를 검증하고 불필요하게 노출하지 않으며, consent와 data plan에 설명된 방식으로만 duplicate check를 적용합니다. Preview mode에서는 실제 redirect를 막고 예정된 outcome을 표시합니다. 실제 collector 설정과 end-to-end verification에는 명시적 승인과 확인된 결과가 필요합니다.
