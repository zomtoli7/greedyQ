# Prolific Module

[한국어](./guide(kor).md)

Confirm which URL parameters identify the participant, study, and session; when they may be stored; duplicate-participation behavior; and separate destinations for completion, screen-out, consent decline, and withdrawal. Never invent completion codes or live return URLs.

Validate required identifiers, avoid exposing them unnecessarily, and apply duplicate checks only as described in the consent and data plan. Preview mode must suppress real redirects and display the intended outcome instead. Live collector configuration and end-to-end verification require explicit approval and verified results.
