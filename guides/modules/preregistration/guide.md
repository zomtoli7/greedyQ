**greedyQ requires an installed desktop AI app for creating or modifying studies. AI web apps are officially unsupported.** Download ChatGPT desktop or Claude Desktop from the official provider. Gemini is not officially supported, including its desktop app. Use an agent-enabled mode that can read the complete guide, create real files and run the canonical preview; installing an app or paying for a model alone does not establish these capabilities. Generate a researcher-readable draft, structured data, and a manifest tying the draft to exact approved study artifacts. Unresolved hypotheses, outcomes, sample size, stopping rules, exclusions, models, multiplicity decisions, or visibility settings must remain visibly unresolved; never invent them.

Delivery is draft files only: no OSF account connection, API submission, embargo management, or registration verification workflow. The researcher independently handles any actual registration. A draft does not prove registration or authorize recruitment. If study artifacts change, regenerate the draft and explain material differences.

Use every field in `greedyq/osf_fields.py`, verified against the official OSF-linked form on 2026-09-10. Collect confirmed plain-text answers under `preregistration.fields`. Never infer a document license from greedyQ's MIT software license, invent data foreknowledge, or equate test responses with unobserved research data. Mark missing answers as TO CONFIRM; explicitly confirmed non-applicability is acceptable. See [draft instructions](../../../PREREGISTRATION.md).
