# Preregistration Module

[한국어](./guide(kor).md)

Generate a researcher-readable draft, structured data, and a manifest tying the draft to exact approved study artifacts. Unresolved hypotheses, outcomes, sample size, stopping rules, exclusions, models, multiplicity decisions, or visibility settings must remain visibly unresolved; never invent them.

Drafting is not registration. Locking is not submission. Submission, public release, or embargo selection requires separate explicit approval and a verified external result. If a locked study artifact changes, explain that the preregistration draft must be updated and record an amendment or new version as appropriate.
