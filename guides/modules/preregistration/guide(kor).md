연구자가 읽는 초안, 구조화 데이터, 그리고 초안과 정확한 승인 연구 산출물을 연결하는 manifest를 만듭니다. 미결정 hypothesis, outcome, sample size, stopping rule, exclusion, model, multiplicity decision, visibility setting은 명시적으로 미결정 상태로 남기며 지어내지 않습니다.

제공 범위는 초안 파일뿐입니다. OSF 계정 연결, API 제출, 엠바고 관리, 등록 상태 검증 절차는 없습니다. 실제 등록은 연구자가 별도로 수행합니다. 초안이 등록이나 모집 승인을 증명하지 않습니다. 연구 산출물이 바뀌면 초안을 갱신하고 중요한 차이를 설명합니다.

2026-09-10 공식 OSF 연결 양식과 대조한 `greedyq/osf_fields.py`의 모든 항목을 사용합니다. 확정한 문장은 `preregistration.fields`에 기록합니다. greedyQ MIT 라이선스를 등록 문서 라이선스로 추정하거나, 데이터 사전 열람 여부를 지어내거나, 테스트 응답을 열람하지 않은 연구 데이터와 동일시하지 않습니다. 미정 답변은 확인 필요로 남깁니다. 연구자가 확인한 해당 없음은 허용합니다. [초안 안내](../../../PREREGISTRATION(kor).md)를 참고하세요.
