# 预注册模块

[English](./guide.md) · [한국어](./guide(kor).md)

生成研究者可读的草稿、结构化数据，以及将草稿与确切已批准研究文件对应的清单。尚未确定的假设、结果、样本量、停止规则、排除、模型、多重检验及公开设置必须明显保留为未决，不能编造。

只交付草稿文件：不连接 OSF 账户、不通过 API 提交、不管理延迟公开，也不提供注册验证流程。实际注册由研究者自行处理。草稿不证明已注册，也不授权招募。研究文件改动时重新生成草稿并说明重要区别。

覆盖 `greedyq/osf_fields.py` 的全部字段，所依据的 OSF 链接表单于 2026-09-10 核对。将确认的纯文本回答写入 `preregistration.fields`。不要从 greedyQ 的 MIT 软件许可推断研究文件许可，不要编造事先接触数据的情况，也不要把试填数据当成未观测研究数据。缺项标为 TO CONFIRM；经明确确认的“不适用”可以接受。见[草稿说明](../../../PREREGISTRATION.md)。
