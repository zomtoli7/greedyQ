# Consent Module

[한국어](./guide(kor).md)

Create a versioned consent page using only confirmed study facts. Describe purpose, activities, duration, foreseeable risks and benefits, compensation, voluntary participation, withdrawal, data collection and retention, contacts, and eligibility in plain language as applicable.

Require an affirmative consent action before collecting research responses or persistent respondent identifiers, except information strictly necessary to display or secure the consent flow. Provide a clear decline path. Never preselect consent or treat navigation as consent. Changes to approved consent text invalidate the relevant approval and require a new recorded version.
