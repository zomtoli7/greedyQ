# CBC 모듈 사용자 여정 검증 — 2026년 10월 26일

[English](./cbc-module-verification-2026-10-26.md)

## 검증 범위

소유자의 기존 Vercel/Supabase 연결에서 가상 Test/Direct 응답으로 진행한 v0.3 개발 검증입니다. 사람을 모집하거나 보상하지 않았으며, 연구 결정을 승인하거나 v0.2 지원 범위를 확대하지 않습니다. CBC는 일반 설문에 삽입하는 기능 모듈입니다. 별도 프로파일이나 사전·사후 문항 전용 형식을 요구하지 않습니다. 첫 계약은 순차적인 일반 페이지 사이에 CBC 한 묶음을 지원합니다.

[모듈 사용 안내](../CBC-MODULE(kor).md)와 [기계 판독 검증 기록](./cbc-module-verification-2026-10-26.json)을 함께 참고하세요. 기존 [클라우드 검증 기록](./cbc-cloud-verification-2026-10-26(kor).md)은 당시의 독립형 시험 기록이며, 이번 검증에서 일반 QMD 결합과 아카이빙을 추가했습니다.

## 제작과 로컬 검증

AI와 설계하기, 빈 CSV/XLSX를 채워 돌아오기, 기존 설계 가져오기에서 선택한 경로와 다음 질문을 유지합니다. `sd_cbc` 삽입 시 기존 일반 문항을 보존하고, 두 번째 CBC 묶음이나 미지원 분기는 거부합니다. 일반 `build`에서 고정 혼합 실행부와 독립적인 컴퓨터·모바일 미리보기 및 구조 보기를 생성합니다. Python과 브라우저의 정규화 모델이 일치하며 임의 R/JavaScript를 실행하지 않습니다.

제작용 ZIP은 포함된 원본 파일을 바이트 단위로 보존하고 응답 다운로드와 자격 증명을 제외합니다. 손상·경로 탈출 파일을 거부하며 새 폴더로 재개합니다. 작성 중인 표를 돌려받을 때 필요한 파일과 작업 단계를 유지합니다. 복제는 새 연구 ID를 만들고 원본을 보존하며 Test 모드와 미승인 상태에서 시작합니다. 버전 업그레이드는 명시적 승인 뒤 별도 사본에 적용하고 버전 표기와 가이드 잠금을 갱신합니다. 분석용 아카이브는 제작용 ZIP과 다릅니다.

## 실제 클라우드 검증

고정 혼합 실행부와 추가 마이그레이션 010을 배포했고 기존 저장 기록이 보존됨을 확인했습니다. 1280px 컴퓨터와 390px 모바일에서 각각 전체 HTTPS 응답을 완료했으며 320px 동의 거부·미완료 페이지도 확인했습니다. 일반 필수 문항의 무응답은 이동을 막고 해당 문항으로 포커스를 옮깁니다. 새로고침 뒤 CBC 과제 순서를 유지하고 마지막 일반 페이지를 마쳐야 완료 시각이 저장됩니다.

철회하면 일반 문항과 CBC 선택·노출·순서·배정·동의가 함께 삭제됩니다. 동의 거부와 CBC 이전 일반 페이지 미완료 시 CBC 과제가 노출되지 않습니다. 보호된 결과 화면은 소유자 인증을 허용하고 비로그인 페이지·API 요청을 거부합니다. 가상 응답은 Test/Direct에만 나타나며 Real에는 나타나지 않습니다. 일반 응답 CSV와 대안별 CBC CSV를 PostgreSQL의 정밀한 원본 값과 대조했으며 철회 답변은 제외됩니다.

첫 혼합 연구에는 가상 응답 7개, 완료 2개, 긴 형태 CSV 24행이 저장됐습니다. 수집 종료 뒤 일곱 테이블 전체와 일반 응답·CBC CSV가 포함된 아카이브를 생성·검사했습니다. 시각 정밀도를 포함해 원본 스냅샷과 일치하며 종료된 수집은 새 참여를 거부합니다. 해당 수집의 재개·재종료 및 복제 연구 등록 전후에 기존 참여자 테이블 전체의 체크섬이 보존됐습니다. 제작 ZIP을 새 폴더로 재개하고 독립된 Test 연구로 복제해 이전 응답을 변경하지 않았습니다.

Vercel 설문·결과 프로젝트를 실제 중지·재개했습니다. 중지된 설문은 503, 결과 화면도 소유자 인증 경로에서 503을 반환했고 결과 접근 보호를 유지했습니다. DB는 이전 시험 사이트와 공유됩니다. 소유자가 해당 사이트의 일시 중단을 명시적으로 승인하고 Supabase를 연결한 뒤 공식 도구로 정확한 프로젝트를 중지·재개했습니다. ACTIVE_HEALTHY → PAUSING → INACTIVE → COMING_UP → ACTIVE_HEALTHY 상태를 확인했습니다. 새 가상 응답을 넣기 전에 참여자 표 일곱 개와 등록 설계·수집 종료 상태·마이그레이션 이력, 총 열 개 표의 행 수와 SHA-256 체크섬이 모두 일치했으며 기존 35개 세션도 보존됐습니다. DB·서비스 키를 관리 권한 대신 사용하지 않았습니다. 일반 아카이빙 기능의 공유 자원 보호 규칙도 유지합니다. 서비스 재개 시 DB 정상 상태를 먼저 확인하며 수집을 자동으로 다시 열지 않습니다.

응답 파일·제작 ZIP·아카이브 내용·세션 접근 정보·계정 자격 증명은 공개 저장소 밖에 보관했습니다. 에이전트의 아카이브 검사를 연구자의 다운로드 확인으로 간주하지 않습니다. 설치된 Chrome으로 시험했으며 화면 너비 시험이 실제 iOS/Android/Safari 검증을 뜻하지는 않습니다.

## 소규모 실제 참여자 시험 전

기술적 Test 묶음은 인접 검증 기록의 설문·보호된 결과 링크에서 검토할 수 있습니다. 실제 모집에는 연구자가 실제 문항·설계, 참여 안내와 실제 연구 연락처, 보관·철회 방침, 모집·반환 경로, 소요 시간과 보상을 승인해야 합니다. 예제의 가상 연락처와 미승인 플래그를 실제 연구 승인으로 재사용하지 않습니다. `cbc-preflight --stage fielding`은 미결정 승인을 알려줄 뿐 게시·모집·지급을 하지 않습니다.

재개 뒤 컴퓨터·모바일에서 일반 문항 → CBC → 일반 문항, 완료 시각, 동의 거부·철회, 보호된 결과, Test/Real 구분과 정확한 CSV를 다시 검증했습니다. 가상 세션 다섯 개를 추가했으며 이 다섯 개를 제외하면 기존 35개 기록의 체크섬이 모두 보존됐습니다. CBC 시험 연구 세 개의 가상 세션은 총 40개이고, 현재 게시된 모듈 연구는 12개 세션·완료 4개·긴 CSV 48행입니다. 실제 CBC 응답은 추가하지 않았습니다.

신규 계정 CBC 연결, 운영 Real 응답 승인 시험, 유료 CBC 참여·반환, 고급 분기·복수 CBC, 네이티브 내보내기와 통계 추정은 별도 검증 사항입니다. 기존 v0.2 Prolific 유료 시험 성공이 CBC 유료 시험의 성공을 뜻하지 않습니다.
