# 종료 시각 수정 및 유료 응답 확인

[English](./terminal-timestamp-fix-2026-10-26.md)

## 원인과 수정

브라우저 저장 경로가 상태와 `updated_at`을 갱신하면서 완료 시 `terminal_at`을 기록하지 않았습니다. CSV는 이 빈 값을 `completed_at`의 빈칸으로 내보냈습니다. 서버 저장 처리의 누락이며, 답변 누락이나 Prolific 반환 오류는 아닙니다.

추가 migration `008_terminal_timestamp.sql`은 진행 중 상태에서 완료·선별 탈락·동의 거부·철회·기술 오류로 처음 전환될 때 서버의 실행 시각을 기록합니다. 재시도와 이후 저장에서도 기존 종료 시각을 유지합니다. 클라이언트 시각은 사용하지 않습니다. 시각과 답변은 같은 트랜잭션으로 저장하며 실패하면 함께 취소됩니다. 과거 종료 기록의 빈 시각은 재저장해도 채우지 않습니다. 001–007 migration은 수정하지 않았습니다.

Build, 배포 검사, migration 적용 기록 검증, 기본 registry, 세 언어의 전체 AI 가이드와 기준 예제에 008을 포함했습니다. 기존 설치는 누락된 기본 migration을 순서대로 적용합니다. CSV는 `terminal_at`을 사용하며 마지막 저장 시각이나 업그레이드 시각으로 대체하지 않습니다.

## 검증

- Python 테스트 194개와 JavaScript·브라우저 테스트 41개가 생략 없이 통과했습니다. PostgreSQL 시험에는 모든 종료 경로, 진행 중 상태, 잘못된 접근 권한, 답변 저장 실패, Prolific 완료, 동시 재전송, 최초 시각 유지, 위조한 클라이언트 시각, 업그레이드 보존과 과거 빈칸 보존을 포함했습니다. 브라우저 CSV 시험에서도 종료 시각 열을 확인했습니다.
- 운영 환경에는 001–006이 적용되어 있었습니다. 기존 파일의 hash를 확인한 후 누락된 응답 스냅샷 migration 007과 시각 migration 008을 적용했습니다. 참가자 페이지나 결과 페이지를 재배포할 필요는 없었습니다.
- 실제 연결에서는 데이터베이스의 독립된 savepoint 안에서 종료 경로 다섯 가지와 Prolific 완료를 시험하고 모든 가상 기록을 되돌렸습니다. 업그레이드를 재시도했을 때 추가 적용은 없었습니다.
- 데이터·모델 테이블 여덟 개의 전체 행을 전후 비교해 일치를 확인했습니다. 세션 94개, 답변 153개, 외부 ID 행 72개, 상태 변경 기록 7개, 연구 계획 9개를 보존했습니다. 배정·동의 이벤트·데이터 요청 테이블은 계속 비어 있습니다. 기존 시각과 답변, 이전 완료 응답의 빈 종료 시각을 보존했습니다. 비공개 근거는 기존 운영 작업공간의 `terminal-timestamp-upgrade.json`입니다.

## 유료 응답과 CSV 대조

연구자가 제공한 Prolific 스크린샷은 제출 1건이 승인 대기 중임을 보여줍니다. 참여자 ID가 저장된 실제 완료 응답과 일치하며 표시된 시작 시각의 분도 맞습니다. 필수 답변 4개는 모두 있고 선택 의견란은 비어 있습니다. 별도의 미완료 실제 기록 1건은 발생 주체가 확인되지 않았습니다. 과거 시험 응답은 연구와 `is_test`로 구분됩니다.

보호된 배포 결과 페이지의 HTML을 가져와 읽기 전용 데이터 스냅샷과 함께 외부 요청이 차단된 독립 로컬 브라우저에서 실행했습니다. 내려받은 CSV에는 실제 응답 2행, 완료 1행, 일치하는 참여자·연구 ID, 올바른 답변, `source=prolific`, `is_test=false`가 들어 있습니다. 기존 `completed_at` 빈칸도 그대로입니다. 이는 배포된 CSV 구현의 확인이며 연구자의 로그인 브라우저를 자동 조작했다는 뜻은 아닙니다. 원본 스냅샷·CSV·ID는 비공개로 보관합니다.

Prolific은 2분 3초, 데이터베이스 생성부터 마지막 저장까지는 약 1분 50초입니다. 집계 지점이 달라 이 차이만으로 답변 유실을 뜻하지 않습니다. 스크린샷은 완료 표식을 보여주며 실제 반환 코드 문자열을 보여주지는 않습니다. 보상 승인·지급 확인·설문 재시작·과거 참여자 데이터의 시각 채우기는 수행하지 않았습니다.

승인된 보관 규칙은 확인 후 30일 이내 삭제입니다. 이번 응답 확인일이 2026-10-26이므로 운영자의 삭제 기한은 2026-11-25이며, 비공개 CSV·스냅샷 사본과 관리용 ID도 포함합니다. 자동 삭제 작업은 예약하지 않았습니다.
