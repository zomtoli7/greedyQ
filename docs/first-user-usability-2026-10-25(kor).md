# 초보 연구자 사용성 점검 — 2026년 10월 25일

[English](./first-user-usability-2026-10-25.md)

실제 초보 연구자를 모집하거나 GPT·Claude를 독립 비교한 연구가 아니라, 연구자·참가자의 행동을 가정한 시나리오 시험입니다. 공개 홈페이지의 프롬프트와 안내에서 출발해 별도 가상 Direct 연구를 만들고 기본 브라우저 실행 코드·데이터베이스 함수·결과·아카이빙을 연결하여 점검했습니다. 유료 Prolific 시험의 배포·계정·설정·응답·예산은 변경하지 않았습니다.

## 여정과 검증 근거

## 수정한 문제

- **조건부 답변 저장:** 화면에서는 숨긴 답을 지웠지만 DB의 이전 답은 남았습니다. 추가 migration `007_answer_snapshot.sql`로 전체 답변 상태 저장이 승인되면 같은 세션에서 빠진 답도 기존 잠금·접근 권한·동의 검사 아래 제거합니다. 과거 기록을 일괄 변경하지 않으며 001–006은 수정하지 않았습니다.
- **결과·CSV:** 연구 이름과 실제 문항·페이지 문구를 표시하고 빈 화면을 설명합니다. 늦게 도착한 이전 조회가 새 필터를 덮어쓰지 못하게 하고 조회 중·실패 시 다운로드를 막았습니다. 다국어 UTF-8·수식 텍스트 보호·커스텀 기반 복합 응답 펼치기·관리 정보와 문항 열 이름 충돌 처리를 추가했습니다.
- **다운로드한 원본 미리보기:** 휴대폰에서도 컴퓨터 폭을 유지하고 휴대폰 프레임 폭을 제한합니다. 결과를 쉬운 말로 알리고 기술 진단은 접어두며 다시 만들기에 실패하면 이전 미리보기를 숨깁니다. 외부 저장 연결을 차단하고 미리보기용 타이머를 적용했습니다.
- **수집 종료:** 실행 중인 설문이 기본 DB의 수집 종료를 감지하면 참가자의 연결 문제로 안내하지 않고 종료 사실을 알립니다. 호스팅 자체가 중지되면 제공업체의 이용 불가 화면이 나올 수 있습니다.
- **동의 기준 예제:** 기존 버전별 연구 안내를 실제 설문에 표시합니다. 로컬 Markdown 문서 참조만으로는 읽을 수 있는 동의 화면이 되지 않았습니다. 연락처가 예제용이라는 표시는 유지합니다.
- **설명서:** ZIP 압축 해제·파일 및 계정 작업 도구·테스트/실제 빈 화면·CSV/ZIP의 비공개 패널 ID·전체 보관과 필터 다운로드의 차이·보관 확인 전 중지 금지·다음 연구와 재개를 안내합니다. 영어·한국어 문서와 홈페이지 3개 언어를 함께 수정합니다.

## 재현

`python3 -m unittest discover -s tests -v`와 `node --test`로 Node 시험 파일들을 실행합니다. 연결 여정은 `PostgresRandomizationTests.test_first_researcher_browser_results_and_archive_journey`가 `tests/first_user_journey.cjs`를 호출합니다. 결과의 순서 역전·오류·내보내기는 `tests/results_usability_browser.cjs`, 제한된 iframe의 홈페이지는 `tests/website_browser.cjs`에서 확인합니다. 에이전트·개발자용 검사이며 연구자는 이 도구를 설치하지 않습니다.

릴리스 전 최종 회귀 검사에서 **Python 176개·Node/브라우저 38개가 모두 통과했고 생략한 검사는 없습니다**. 버전 기록과 생성 산출물은 버전 반영 후 다시 검사합니다.

## 남은 외부 검증 범위

007과 이번 실행 코드 변경은 로컬 검증입니다. 기존 클라우드 연구는 승인된 migration·다시 만들기·모델 등록·배포 검토가 따로 필요하며 저장소·홈페이지 변경만으로 운영 설문은 갱신되지 않습니다. 특히 Prolific 검토 중인 유료 시험은 변경하지 않습니다. 실제 유료 제출 대조·승인·지급은 계속 미검증입니다. 가짜 서비스 시험으로 다른 계정의 권한·요금 한도·Vercel 인증·실제 중지/재개를 검증했다고 주장하지 않습니다. 과거 실서비스 기록은 당시 시험 버전에 대한 근거로 유지합니다.

게시 확인: 버전 `0.2_2026-10-25_7beafe4` 반영 후 전체 214개 회귀 검사를 다시 통과했습니다. GitHub Pages의 생성 임베드·버전 정보가 원본과 일치하며, Safari 게시 후 기존 Google Sites 공개 페이지에서도 전체 임베드의 일치를 별도로 확인했습니다.
