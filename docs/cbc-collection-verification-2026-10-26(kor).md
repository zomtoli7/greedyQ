## 구현 경계

별도의 `0.3-collection.1` 묶음과 `cbc-1` RPC로, Python·브라우저 가져오기 및 공통 표시 코드를 기존 응답 표 7개·보호된 결과·보관에 연결했습니다. v0.2 CBC 문항 등록·QMD 혼합 작성·네이티브 CBC 내보내기·통계 추정기를 제공한다고 주장하지 않습니다. 기존 클라우드 설문 재배포, 실제 참여자 자료 읽기·변경, 모집·지급은 하지 않았습니다.

## 실제 로컬 데이터베이스·브라우저 검사

`tests/test_cbc_collection.py`는 일회용 PostgreSQL 17을 만들고 기존 001–008과 추가 009를 적용하며 실제 `anon` 권한으로 참여자 호출을 시험합니다. 동의 전 배정·노출 차단, 거부, 버전·문구 해시 동의 기록, 서버 가중 블록 하나 배정, 과제·대안 순서 유지, 배정 블록만 반환, 잘못된 권한·선택·revision, 완료 시각, 동시 동일 요청·오래된 충돌 요청, 철회 시 응답·노출·순서·동의 삭제, 불변 등록 모델, 실제·허가된 Test 구분, Prolific 신원·반복 시험 분리, 기존 경로 우회 차단을 검사합니다.

Python에서 실행하는 `tests/cbc_collection_journey.cjs`는 실제 고정 참가자 화면·보호된 결과 화면/API·실제 SQL 함수를 로컬 PostgREST 형태 어댑터로 연결합니다. 어댑터는 전송과 가상 연구자 인증만 담당하며 동의·배정·저장·철회 로직은 흉내 내지 않습니다. 데이터베이스에서 실행합니다. 로컬 서버와 가로챈 가상 Supabase 주소 이외 전송은 차단합니다.

컴퓨터·모바일 동의/거부, 동의 전 문항 없음, 필수 선택 안내·포커스, 이전·새로고침, 저장 전 장애, 저장됐지만 답신이 유실된 뒤 중복 없는 재시도, 완료·새로고침, 가상 production 안의 허가된 Test, 철회·새로고침, 미완료, 비로그인 결과 차단, 실제/Test/Source 필터, 실제 긴 CSV 다운로드, 수집 종료, 전체 ZIP 보관을 검사합니다. 예상 가상 결과는 세션 5개·완료 2개·미응답 과제 하나를 포함한 실제 구분 대안 행 15개·Test 대안 행 12개이며 철회/거부의 선택 행은 없습니다. 같은 저장 자료로 Python·브라우저 긴 행 변환도 대조합니다. 유료·사람 참여 검증으로 간주하지 않습니다.

## 노출·내보내기 의미

서버 `served_at`과 브라우저 표시 확인 `presented_at`을 분리했습니다. 다음 화면 답신이 유실된 서버 준비 과제는 표시 확인이나 응답 전까지 `available`이며 관측된 표시로 계산하지 않습니다. `answered_at`도 서버 시각입니다. 선택 null은 빈칸으로 유지하고 명시적 none과 구분합니다. none의 속성 칸은 비웁니다. 완료 시각은 재시도로 바뀌지 않습니다. 철회하면 CBC 선택·노출과 개인별 순서를 지우고 기존에 안내한 관리 정보 경계만 유지합니다.

`tests/cbc_results_api.cjs`는 가상 세션 103개·응답 2,003개와 서버 200행 제한에서 전체 페이지 읽기·ID 묶음 조회, 인증된 페이지 출처에서 서비스 전용 RPC로 시험 링크 발급, 후속 페이지 실패 시 잘린 성공 반환 금지를 검사합니다. 실제 결과 프로젝트는 모든 배포와 `/api/results`에 Vercel Authentication이 필요하며, 로컬 어댑터 시험이 실제 제공업체 보호 설정 검증을 대신하지 않습니다.
