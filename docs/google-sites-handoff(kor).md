# Google Sites 편집 인계

[English](./google-sites-handoff.md)

먼저 같은 폴더의 `google-sites-plan(kor).md`를 읽으세요. 현재 버전의 웹사이트 원본과 전체 교체 임베드는 `website/`에 있고 릴리스·이력은 `release.json`과 `updates/0.2/`에서 생성합니다. `website/copy-embed.html`에서 한 번에 코드를 복사할 수 있습니다. 이 파일의 생성·GitHub 반영만으로 Google Sites 편집이 저장·게시되지는 않습니다. 일부 인계 파일로 기존 저장소를 덮어쓰지 않습니다.

## 현재 소유자 결정

- 개인 Google 계정의 Google Sites를 사용합니다.
- 공개 주소: https://sites.google.com/view/greedyq
- 소유자는 greedyq.org 포워딩을 이미 설정했다고 알려왔습니다. 그대로 보존하고 DNS를 변경하거나 새 도메인 연결을 요구하지 마세요.
- 소유자는 로컬 작업에서 편집 화면 접근에 성공했다고 알려왔습니다. 원격 파일 경로가 아닌 해당 로컬 작업의 승인된 브라우저로 계속하세요.
- 편집 전 기존 페이지를 확인하고 내용을 보존하세요. 초안 편집과 자동 저장은 승인됐습니다. 별도 승인 없이 게시 버튼, 공유 권한, 도메인을 변경하지 마세요.

## 작업 범위

계획서와 포함된 영문·한국어 가이드로 비기술 연구자를 위한 작업 중심 웹사이트 초안을 준비하세요. 기능 설명 전에 호환성 점검표를 읽으세요. 사전등록은 초안 파일 제공이며 OSF 연동이 아닙니다. Surveydown 전체 호환을 약속하지 마세요. 공개 갤러리는 링크 작동 확인 후 임베드하고 비공개 결과나 실제 응답은 포함하지 마세요. 변경한 페이지와 남은 확인 사항을 정리해 소유자에게 초안 검토를 요청하세요. 필요한 원본이 없으면 내용을 지어내지 말고 무엇이 필요한지 알려주세요.
