## Repeatable agent check

`tools/verify_cbc_cloud.cjs` is an opt-in live test tool, not part of ordinary offline tests. It requires `GREEDYQ_CBC_CLOUD_TEST=1`, an explicit private evidence directory and connection file, exact survey/results URLs and study ID. Before browser data entry it refuses a registered production/panel study, real responses in the target study, or a participant descriptor that does not match the Test/Direct model. Results identity is checked too. The agent supplies authorized private Results cookies; the researcher is not asked to expose secrets or run SQL.

Provide `GREEDYQ_CBC_EVIDENCE_DIR`, `GREEDYQ_CBC_ENV_FILE`, `GREEDYQ_CBC_SURVEY_URL`, `GREEDYQ_CBC_RESULTS_URL` and `GREEDYQ_CBC_STUDY_ID`. The private connection file supplies Supabase/PostgreSQL variables. Configure `NODE_PATH`/`GREEDYQ_CBC_PG_MODULE`, `GREEDYQ_PYTHON` and an installed Chrome as required by the agent host. The tool adds synthetic sessions and withdraws only its own withdrawal case. It never registers a production plan, recruits, pays, closes a study or deletes unrelated records.
