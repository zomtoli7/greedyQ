# v0.2 지원 범위 마감

[English](./v0.2-closeout-2026-10-26.md)

## 마감 결정

지원하는 v0.2 설문·실험 실행 환경을 유지하면서 v0.3은 CBC 명세와 골든 레퍼런스 설계부터 시작합니다. 이번 마감으로 CBC를 활성화·배포하거나 동작한다고 주장하지 않습니다. 홈페이지 내용·게시는 별도 홈페이지 Work가 담당합니다.

## 문서와 종료 안내 점검

유료 시험이 중지됐거나 지급 미확인이라고 남아 있던 로드맵·연결 준비 설명을 고쳤습니다. 응답·제출·CSV 일치는 에이전트가 검사했고 승인·지급은 연구자가 명시적으로 확인했으며 영수증을 독립 감사하지 않았습니다. 지원되는 선택지·페이지 섞기와 native export 한계를 구분하고 가중 비율을 미구현으로 나열하지 않도록 정리했습니다. 모든 native custom control의 동작 대조, 보조기술 접근성, 호스트 간 연구는 완전한 동등성을 주장하지 않는 후속 검증으로 남겼습니다.

기본 실행 환경은 이미 `study_closed`를 구분해 종료 안내를 표시하고 있었습니다. 앞서 추가 구현이 필요하다고 한 설명은 오래된 문서를 근거로 한 것이었습니다. 네 참여자 언어·컴퓨터/모바일·시작 시 종료·응답 도중 저장 시 종료를 포함한 열여섯 상황과 일반 통신 오류 구분을 회귀 시험에 추가했습니다. 기존 로컬 PostgreSQL·브라우저 아카이빙 여정은 실제 종료 차단도 시험합니다. 중복 실행 코드나 새 SQL migration은 필요하지 않았습니다.

## 연구자가 요청한 즉시 삭제

2026-10-26 연구자는 11월 25일까지 보관하는 대신 이번 마감에서 삭제하도록 명시적으로 선택했습니다. 전용 시험 데이터베이스의 기록은 검토한 유료·가상 연구 ID 일곱 개와 일치했으며 다른 연구는 발견되지 않았습니다.

하나의 트랜잭션에서 관련 테이블을 잠그고 대상 세션·종속 답변·ID·이벤트를 제거하고 시험 미리보기 권한을 없앤 뒤 기본 수집 종료 차단을 설치했습니다. 모델·migration 적용 기록·인증 정보는 보존했습니다. 가상 새 시작이 종료 상태로 거부되는 것을 확인하고 되돌렸습니다. Prolific 제출·승인·지급 기록은 변경하지 않았으며 서비스 프로젝트 중지·삭제나 새 모집은 하지 않았습니다.

| 기록 | 삭제 전 | 삭제 후 |
| --- | ---: | ---: |
| 세션 | 94 | 0 |
| 답변 | 153 | 0 |
| 외부 ID 행 | 72 | 0 |
| 상태 변경 이벤트 | 7 | 0 |
| 배정·동의 이벤트·자료 요청 | 각각 0 | 각각 0 |

지운 응답 ID나 CSV를 포함한 운영자의 비공개 사본·스크립트 열세 개를 제거했습니다. 전용 운영 폴더 재검사에서 알려진 참여자·세션 ID가 더 발견되지 않았고 CSV·ZIP 사본도 없었습니다. 비공개 삭제 근거에는 원본 참여자 자료 대신 개수와 작업만 기록합니다. 모델 정의와 비식별 기술 근거는 유지합니다.

이는 운영 데이터베이스와 검사한 운영 폴더의 삭제 확인입니다. Prolific 지급·제출 기록, 서비스 관리 백업, 연구자가 직접 받은 파일, 첨부물이나 대화 이력까지 지웠다는 뜻은 아닙니다. 자동 보관 작업도 설정하지 않았습니다. 검사한 자료의 11월 25일 정리 계획은 이번 조기 삭제 완료로 대체합니다.

## v0.3 전달과 남은 범위

[CBC 기획 묶음](../drafts/v0.3/cbc/README(kor).md)에 `greedyQCBC` 제안 계약, 온라인 강좌 가상 골든 설계, 빈 CSV·XLSX, 예상 가상 긴 형태 자료와 초안 검사기를 준비했습니다. 연구자가 AI 협업·빈 표 직접 작성·기존 표 가져오기 중 선택합니다. v0.2 파서와 공개 registry는 계속 CBC를 거부합니다.

골든 예제는 통계적으로 최적화된 설계·검증된 측정도구·승인된 실제 연구가 아닙니다. Python·브라우저 실제 가져오기, 브라우저 XLSX 읽기, CBC 표시, 서버 저장과 실제 수집은 이후 구현입니다. 완료 시각 수정 후 첫 새 실제 응답과 유료 내부 선별은 아직 미검증입니다. 이번 전달만으로 추가 유료 시험을 승인하지 않습니다.

## 검증

최종 버전 정리 전후 모두 Python 테스트 202개와 JavaScript·브라우저 테스트 42개, 총 244개가 생략 없이 통과했으며 CBC 초안 자료 여덟 시험과 종료 안내 시험을 포함합니다. 최종 가이드 잠금·migration manifest·버전 출처도 확인했습니다. XLSX 열 이름·빈 입력·매크로와 수식 없음도 검사하고 두 시트를 시각 확인합니다. 로컬·실제 연결 시험과 승인된 삭제의 기록이며 모든 브라우저·native exporter·새 계정을 검증한 것은 아닙니다.
