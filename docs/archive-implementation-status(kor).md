# 아카이빙 구현 상태

과거 로컬 구현 시점의 기록입니다. 최신 상태는 [실서비스 반복 사용자 인수 검사](./repeat-user-acceptance(kor).md)를 참고하세요.

[English](./archive-implementation-status.md)

2026-09-10 로컬 구현 상태이며 새 버전 발행이나 실제 서비스 중지 인수 검사 결과가 아닙니다.

- 검증된 TLS, 마이그레이션 해시·재시도 이력, 분리된 배포 묶음, 모든 별칭의 결과 보호를 재사용 클라우드 도구에 반영했습니다.
- 운영용 보관 CLI를 추가했습니다. 연구를 닫고 전체 비공개 데이터를 내보낸 뒤 검증된 ZIP과 실제·테스트 CSV를 생성하며, 다운로드 확인 후 서비스 중지를 요청·검증합니다.
- 잘못된 ID, 변경 파일, 공유 연구, 미처리 데이터 요청, 일부 실패와 재시도를 방어합니다. 프로젝트를 삭제하지 않습니다.
- 영문·한국어 사용자 안내와 운영 규약을 core 가이드·레지스트리·첨부용 가이드에 연결하고 기준 예제의 지침 기록을 동기화했습니다.
- 로컬 보관 검사와 모의 서비스 검사가 통과했습니다. 데이터베이스 종료 SQL과 실제 서비스 중지·복원은 별도로 승인된 실서비스 인수 검사가 필요합니다. 현재 온라인 테스트 프로젝트는 유지됩니다.

로컬 테스트 통과가 새 계정 관리 연동의 설치 완료를 증명하지는 않습니다. 기존 Marketplace 연결 정보만으로는 Supabase 관리 권한을 추가 승인받아야 할 수 있습니다.
