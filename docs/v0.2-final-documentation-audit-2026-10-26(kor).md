# v0.2 최종 문서 점검 — 2026년 10월 26일

[English](./v0.2-final-documentation-audit-2026-10-26.md)

## 범위와 버전 경계

지원되는 v0.2 설문·실험 사용 과정, 제작 환경 정책, 연구자 안내를 마감 점검합니다. 같은 저장소에 선택적 초안 코드·예제가 있어도 CBC는 v0.3 개발 기능입니다. CBC 클라우드·유료 승인은 검증되지 않았습니다. 이번 점검은 배포된 설문·데이터베이스·모집·지급 상태를 바꾸지 않았습니다. Google Sites 게시에는 브라우저 기능이 있는 워크가 필요합니다. 현재 이 작업에는 브라우저 제어 도구가 없어 게시 완료로 보고하지 않습니다.

## 네 차례의 점검

1. **원문 정책 대조.** 과거·아카이브 기록 및 생성된 코드 본문을 제외한 현재 Markdown을 확인했습니다. 일반 Chat만으로 제작한다는 옛 약속과 Gemini 가져오기 링크 이름을 정리했습니다. 첫 앱 확인과 환경 불명 시 질문을 유지합니다. 필요한 도구가 있는 설치된 ChatGPT·Claude 데스크톱만 제작을 지원합니다. Gemini는 향후 지원 검토, Meta AI·Grok·DeepSeek는 후보입니다.
2. **기능·검증 사실 대조.** README에서 유료 시험을 아직 검토 대기 중이라고 하던 설명을 완료·승인·지급 기록에 맞췄습니다. 연구자의 지급 확인과 독립 영수증 검증은 구분합니다. 구현 전이라는 제품 상태, 중국어 전체 가이드와 로컬 실행 문서의 migration 수를 수정해 v0.2 전체 8개와 맞췄습니다. CBC 구조 예시는 사용 가능한 v0.2 프로필이 아닌 v0.3 목표로 표시했습니다. 과거 관찰은 삭제하지 않고 현재 상태 링크를 추가했습니다.
3. **파일 간·생성물 대조.** 현재 Markdown 목록, 이스케이프 괄호를 포함한 로컬 링크, 영어·한국어 짝, 3개 언어 입구·홈페이지, 레지스트리 해시, 포함된 고정 소스, 예제 잠금 파일과 릴리스 출처를 확인합니다. 파생 파일을 정해진 도구로 다시 생성하며 고정 실행 코드나 적용된 SQL을 임의로 바꾸지 않습니다. 최종 집계는 짝지은 JSON 기록에 저장합니다.
4. **다시 생성한 뒤 검사·화면 확인.** 최종 버전 기록 전후로 전체 Python·JavaScript/브라우저 검사를 실행합니다. 새 호환성 페이지를 3개 언어·320/1280px에서 확인하고 시작 프롬프트 앞의 지원 안내를 점검합니다. 모든 복사 블록, 최신·대체·수동 복사, 줄바꿈 손실 후 URL 구분과 BibTeX 보존을 확인합니다. 로컬 HTML 검사가 Google Sites 게시나 특정 AI 계정의 적합성을 입증하지는 않습니다.

## 검증과 남은 범위

버전 기록 전 전체 회귀 검사는 **Python 238개 + Node/브라우저 57개, 총 295개**가 실패·생략 없이 통과했습니다. CBC 개발 검사를 포함한 저장소 회귀 검사이며 CBC를 v0.2에 추가하거나 특정 AI 계정을 인증하는 것은 아닙니다. 최종 버전 기록 후 결과는 아래에 별도 기록합니다. 홈페이지 복사는 3개 언어·2개 폭에서 **270건**을 대조합니다. 이 작업은 Google Sites의 공개·편집 상태를 바꾸거나 전체 소스를 대조하지 않았습니다.

Prolific 기본 1인 유료 경로는 완료 기록이 있습니다. 서명 링크, 실제 수집 반복 제출, 유료 별도 선별, 008 적용 후 새 유료 응답의 시각, 독립 지급 영수증은 해당 시험의 검증 범위 밖입니다. CBC 수집은 로컬 가상 PostgreSQL/브라우저 검증이며 클라우드·유료 승인이 아닙니다. 기존 비공개 데이터와 프로젝트 소유자 PDF는 공개 저장소에 포함하지 않습니다.
