# Vercel: Onboard your agent

[English](./vercel-agent-onboarding.md)

2026-10-25 검토. 공개 버튼은 다음 요청을 복사합니다: `Set up Vercel for me. Fetch https://vercel.com/get-started.md and follow it.`

[공식 안내](https://vercel.com/get-started.md)는 Vercel CLI, 플랫폼 지침(플러그인 우선, 지원되지 않으면 개별 스킬), 공식 MCP 연결을 준비합니다. 컴퓨터·에이전트 준비와 이후 프로젝트 작업을 구분하며, 계정 소유자의 로그인·승인은 여전히 필요합니다. 이 기능만으로 greedyQ 연구 생성, Supabase 설정, 응답 저장 검증 또는 설문 게시가 완료되지는 않습니다.

연구자가 Vercel 연결을 요청했을 때 선택적 준비 경로로 사용합니다. 먼저 기존 도구·연결을 확인하고, 인증된 공식 연결이 있으면 재사용하세요. 플러그인과 스킬을 중복 설치하거나 다른 MCP 설정을 덮어쓰지 마세요. 전역 연결 준비 중에는 프로젝트를 생성·연결하지 않습니다. 호스트별 지원이 다르므로 최신 [공식 MCP 연결 안내](https://vercel.com/docs/agent-resources/vercel-mcp)를 따르세요. CLI 설정만으로 데스크톱이나 브라우저 전용 호스트의 연결이 입증되는 것은 아닙니다. 프로젝트 작업 전에 읽기 전용 팀 목록 조회로 연결을 확인합니다.

연구자에게는 “미리보기가 준비되었습니다. 온라인으로 공개하려면 Vercel에 로그인하고 요청되는 연결을 승인해 주세요. 그다음 설문·결과 링크·데이터 연결을 준비하고 확인하겠습니다.”라고 설명할 수 있습니다. 호스트가 Vercel을 조작할 수 없으면 완성된 연구 폴더를 보존하고 가능한 인계 방법을 안내합니다. 비밀번호나 비공개 토큰을 일반 대화에 붙여 넣도록 요청하지 않습니다.

이번 검토에서는 공개 문서와 버튼만 확인했습니다. 전역 도구 설치·인증 시작·클라우드 프로젝트 변경은 수행하지 않았습니다. Claude 시험은 로그인에서 멈췄으므로 외부 배포 성공의 근거가 되지 않습니다. 유료 Prolific 시험은 이번 검토 범위에 포함되지 않습니다.
