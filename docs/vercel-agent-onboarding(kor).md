# Vercel 연결과 선택적 에이전트 온보딩

[English](./vercel-agent-onboarding.md) · [简体中文](./vercel-agent-onboarding(zh-CN).md)

## 기본 여정

기존 연구자 여정인 설문 검토 → Vercel 로그인 → 필요한 Vercel/Supabase 접근 승인 → 검증한 설문·결과 링크 전달을 유지합니다. **Onboard your agent는 선택 사항이며 필수가 아닙니다.** 일반적인 greedyQ 사용을 위해 연구자가 CLI를 설치하거나 플러그인을 설정하거나 앱을 재시작할 필요는 없습니다.

AI는 먼저 기존 연결을 확인합니다. 이미 사용 가능한 승인된 공식 Vercel 연결이 있으면 인증 계정·대상 팀을 확인한 뒤 지원하는 작업에 우선 사용합니다. 없으면 기존의 지원되는 CLI/통합 경로를 사용합니다. 연결별 권한 범위를 독립적으로 검증하고 같은 연구 승인·기본 파일·데이터 경계·배포 검수를 유지합니다. 공식 연결을 써도 연구의 승인자나 접근 권한은 달라지지 않습니다.

## 팀 접근 승인이 빠진 경우

계정 로그인에 성공해도 팀 목록이 비거나 대상 팀 접근이 거절될 수 있습니다. 프로젝트가 없다고 단정하거나 계정 전체를 재연결하거나 인증 정보를 지우거나 거절된 권한을 다른 인증으로 몰래 우회하지 않습니다. 알고 있는 대상 팀에 제공자의 접근 복구 절차를 사용합니다. `authorize_team_access`가 `requires_user_action`을 반환하면 정확한 링크와 만료 안내를 보여주고 직접 승인할 때까지 기다린 뒤 같은 연결로 원래 요청을 재확인합니다. SSO가 없어도 필요할 수 있습니다. 임시 승인 링크나 인증 정보를 공개하지 않습니다.

“계정은 연결되었습니다. 이 연구팀 접근을 승인해 주시면 다시 확인하겠습니다.”라고 간단히 설명합니다.

## 선택적 Onboard your agent

Vercel 버튼은 `Set up Vercel for me. Fetch https://vercel.com/get-started.md and follow it.`을 복사합니다. [공식 안내](https://vercel.com/get-started.md)는 CLI·가이드/플러그인·공식 MCP 연결을 준비합니다. 이것만으로 greedyQ 연구 생성·Supabase 설정·저장 검증·설문 배포가 완료되지는 않습니다.

연구자가 요청하거나 반복 사용을 위해 지원 AI 호스트를 준비하려는 경우 선택적으로 안내합니다. 기존 도구를 재사용하고 플러그인 또는 개별 가이드 중 하나만 한 번 설치합니다. 다른 설정을 보존하고 연결을 중복 추가하지 않습니다. 최신 [공식 호스트 연결 안내](https://vercel.com/docs/agent-resources/vercel-mcp)를 따르세요. CLI 설정만으로 데스크톱/브라우저 호스트가 도구를 불러왔다고 할 수 없습니다. 먼저 갱신하고 새 도구가 계속 나타나지 않을 때만 재시작합니다. 전역 연결 준비 중에는 프로젝트 생성·연결, 데이터베이스 설정, 배포, 모집을 하지 않으며 변경 확인을 유지합니다.

## 실제 검증 범위

2026-10-25 관리자의 시험 환경에서 선택적 온보딩을 수행했습니다. Vercel CLI 65.2.0, 기존 로그인 재사용, Codex Vercel 플러그인 설치, 공식 MCP 인증, 새 도구 로딩을 위한 앱 재시작과 별도의 대상 팀 승인을 확인했습니다. 공식 문서 검색·인증된 팀 목록 조회·대상 팀 접근이 모두 성공했습니다. 첫 팀 목록은 비었고 직접 팀을 조회하면서 빠진 접근 승인을 확인했습니다. 따라서 로그인만으로 팀 접근 완료를 보고해서는 안 됩니다.

이 근거는 해당 환경의 연결 준비와 읽기 작업을 검증합니다. 새 MCP 경로로 배포·Supabase 설정, 다른 계정/호스트, 모집·지급까지 검증한 것은 아닙니다. 기존 설문·결과 배포와 유료 Prolific 시험은 변경하지 않았습니다. 앞선 Claude 시험도 Vercel 로그인에서 멈췄으므로 배포 검증 근거가 되지 않습니다.

실제 배포에는 가상 응답 저장·보호된 결과·명시적 수집 승인을 포함한 [배포 모듈](../guides/modules/deployment-vercel-supabase/guide(kor).md)을 따릅니다. 어느 연결 경로도 사용할 수 없다면 전체 연구 폴더를 보존하고 가능한 인계 방법을 정확히 안내합니다.
