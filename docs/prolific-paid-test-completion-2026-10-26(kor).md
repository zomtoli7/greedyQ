## 결과와 확인 근거

2026-10-26 연구자가 참여자 승인과 보상 지급을 완료했다고 확인했습니다. Prolific 유입, 답변 저장, 완료 처리, 결과·CSV 대조, 연구자의 승인·지급 확인까지 기본적인 1명 유료 연결 시험을 마쳤습니다. 연결과 사용 흐름을 확인한 것이며 연구 설계의 타당성이나 Prolific의 모든 기능을 검증한 것은 아닙니다.

## 유료 정상 완료와 별도로 확인한 것

실제 초안 Preview에서 정상 완료·동의 거부·철회·새 시험 시작을 확인했으며 실제 중복 참여 제한은 유지했습니다. 철회 시 답변 삭제, 동시 저장 보호, 시험·실제 분리, 재접속과 CSV 동작은 로컬·실제 연결 근거가 있습니다. 유료 참여자에게 동의 거부나 철회를 수행하게 했다는 뜻은 아닙니다.

## 남은 확인 범위

- **008 적용 뒤 첫 유료 응답:** 로컬·실제 연결의 가상 시험에서 최초 종료 시각 기록과 유지가 확인됐습니다. 대조한 유료 응답은 수정 전 기록이므로 빈 시각을 그대로 보존했습니다. 수정 후 새 실제 응답으로는 아직 확인하지 않았으며 다음 승인된 연구의 첫 응답에서 확인할 수 있습니다.
- **유료 설문 내부 선별:** 분기 구현과 로컬·가상 시험은 있지만 실제 유료 연구의 “Screened out” 경로와 보상은 시험하지 않았습니다. 사용하는 연구에서 확인해야 합니다.
- **추가 환경과 규모:** 새 계정·연구·기관·표본 규모·별도 배정 방식 모두를 이번 시험으로 검증한 것은 아닙니다. 실제 설계에 필요한 검사를 합니다.
- **영수증 검사:** 지급은 연구자가 확인했으며 별도의 영수증·거래 내역을 직접 조회하지 않았습니다.
- **미지원 기능:** 서명 링크 검증, 모집·지급 API 자동화, 실제 반복 제출 연구는 기본 URL 연동의 확립된 기능이 아닙니다. 기본 시험 완료를 위해 반드시 남아 있는 작업은 아닙니다.
- **자료 정리:** 승인된 30일 보관 규칙에 따라 2026-11-25까지 시험 답변·관리용 ID·운영자의 비공개 CSV·스냅샷 사본을 삭제해야 합니다. 운영자의 후속 작업이며 자동 삭제 예약이나 삭제 완료를 주장하지 않습니다.
- **미완료 기록:** 이번 연구에는 발생 주체가 확인되지 않은 미완료 실제 기록 1건이 추가로 있습니다. 별도의 검증된 유료 참여자로 간주하지 않았으며 삭제·재분류하지 않았습니다.

기본 경로를 다시 확인한다는 이유만으로 추가 유료 시험을 할 필요는 없습니다. 표본 확대·보상 변경·모집·승인·지급은 연구자의 별도 결정 없이 수행하지 않습니다.

## 릴리스 검증

버전 정리 후 Python 테스트 194개와 JavaScript·브라우저 테스트 41개가 생략 없이 통과했습니다. 생성한 홈페이지는 `website/publication-manifest.json`의 버전·바이트 수·SHA-256과 일치합니다. 영어·한국어·중국어 탐색, 히스토리, 제한된 모바일 환경의 프롬프트 복사가 브라우저 시험을 통과했습니다. 로컬·소스 검증이며 Google Sites 게시나 추가 외부 지급 조회를 뜻하지 않습니다.
