# CBC 가져오기·미리보기 검증 — 2026년 10월 26일

[English](./cbc-preview-verification-2026-10-26.md)

## 구현 범위

Python 기준 구현(`greedyq/cbc.py`)을 먼저 만든 뒤 동일 계약의 브라우저 JavaScript(`web/greedyq-cbc.js`)와 고정 단일 파일 컴퓨터·모바일 미리보기를 구현했습니다. CSV·값만 담은 XLSX를 읽어 `0.3-preview.1`로 정규화합니다. 실제 수집용 공개 프로파일·설문 형식은 v0.2를 유지합니다. 별도의 v0.3 미리보기이며 실제 CBC 수집 출시는 아닙니다.

골든 설계: 속성 4개, 수준 12개, 블록 2개, 과제 8개, 일반 프로필 16개. 기본 정규화 설계 SHA-256: `1ebf1ff0ac5890af59a46987099f7b8e58934e9ae868b1dee21ac2d4ae3990bc`. 이전 기획 manifest는 다른 초안 구조를 해시했으므로 값이 다릅니다. 원본 CSV와 이전 가상 응답 예제는 보존했습니다.

## 수행한 검사

- `tests/test_cbc_import.py`: Python CSV·인라인/공유 문자열 XLSX의 동일 결과, 실제 빈 Excel, 부분·중복·미등록 코드, 동일 프로필, 잘못된 개수·가중치·순서 방식, 확정한 금지 조합, 다국어·쉼표·줄바꿈·BOM/CRLF·앞자리 0 유지, 해시, 내보내기 관리 열 이름 충돌, 정수 의미의 JSON 숫자 일치, 위험 압축 파일·수식·외부 링크·매크로·DTD/entity·병합 칸 거부, 원본 경로 제한, 안전한 단일 HTML, 실패 시 출력 파일 미생성.
- `tests/cbc_browser.cjs`: 브라우저 CSV/XLSX가 Python과 해시까지 완전히 일치, 위험 Excel·실제 빈 표 거부와 오류 코드, 미응답/none 구분, 내보내기 열·선택 행, 독립적인 두 화면, 필수 안내·포커스, 이전·새로고침·순서 유지, 완료, 실제 CSV 다운로드, 가상 철회 시 응답·표시 순서 삭제 후 최소 표시만 저장, 구조 보기, 잘못된 가져오기 후 이전 미리보기 숨김, 외부 HTTP 전송 없음.
- 화면 폭 320·390·900·1280픽셀에서 검사했습니다. 컴퓨터 화면은 자체 스크롤 프레임 안에서 넓게 유지하며 모바일은 최대 390픽셀입니다. 페이지 전체 좌우 스크롤이 없습니다. 대안 2개 비교표·3개 모바일 카드, none 끄기, 공격성 문구의 텍스트 표시, 키보드 선택, 설계 해시별 세션 분리를 시험했습니다.
- 영어·한국어·중국어 간체·번체의 화면 안내를 확인했습니다. 연구자가 작성한 속성·수준 문구는 몰래 번역하지 않고 유지합니다.
- 소스·릴리스 재생성 뒤 기존 Python·브라우저 회귀 테스트를 다시 수행합니다. 최종 개수는 커밋에 연결된 업데이트 기록에 남깁니다.

실제 브라우저 시험에서 320픽셀 화면의 파일 선택 칸이 넘치는 문제를 발견해 내부 너비를 제한했습니다. 속성 ID가 CSV 관리 열을 덮어쓸 가능성도 발견해 해당 이름을 거부합니다. 시험 전용 우회 경로는 넣지 않았습니다.

## 검증 한계와 남은 관문

브라우저 자동 시험 환경은 macOS의 설치된 Chrome 헤드리스입니다. 모든 브라우저 버전·터치 기기·보조공학 기기를 검증한 것은 아닙니다. Excel 압축 해제를 지원하지 않으면 오류와 CSV 대안을 안내합니다. 로컬 저장소가 없거나 지워질 수 있습니다. 가상 철회는 이미 다운로드한 CSV를 지우지 않습니다.

실제 CBC schema/RPC·동의 흐름·클라우드 결과 연결·실제/시험 권한·surveydown CBC 내보내기는 설치하거나 검증하지 않았습니다. Prolific 연구 게시·지급·수정은 하지 않았습니다. 이번 작업을 위해 Vercel/Supabase 참여자 자료를 읽거나 변경하지 않았습니다. 통계적 균형·효율·식별·검정력·추정 타당성은 연구자와 통계 검토의 별도 과제입니다.
