# Claude 첫 연구 시험 후속 조치

[English](./claude-build-review.md)

2026-10-25 제공된 `greedyQ-build-deploy-test.md`를 검토했습니다. 붙여 넣은 HTML은 검토 시작 당시의 홈페이지 임베드와 완전히 같으며 별도의 시험 보고서는 아닙니다. Claude의 원래 연구 폴더는 제공되지 않아 독립적으로 만든 가상 연구로 문제를 재현했습니다. 검토 중인 실제 유료 Prolific 시험은 변경하지 않았습니다.

| 보고서 | 조치와 검증 범위 |
| --- | --- |
| P0-A, P1-D: 파일·기록 누락 | `init`은 문항·승인을 만들어내지 않고 전체 초안 폴더와 미정 기록을 생성합니다. build는 기본 마이그레이션 001–007, Vercel 설정·환경 예제를 제공합니다. 묶음 검사는 연구 기록·지정 문서·안전한 경로·연구 식별 정보·해시를 확인합니다. |
| P0-B: 조작하지 않은 슬라이더 응답 | 숫자·범주 슬라이더는 참가자의 조작 또는 명시한 초기값 전에는 미응답입니다. 선택 문항도 그대로 비워 둡니다. 컴퓨터·모바일에서 필수 검증·키보드 조작·명시 초기값 보존을 확인합니다. 날짜도 오늘을 자동 응답으로 넣지 않습니다. |
| P0-C, P2-B: Python 화면 차이·입력 소실 | `run`은 미리보기·배포와 같은 JavaScript 화면을 제공합니다. Python은 백엔드·파서 기준 구현이고 기존 Python 화면은 참가자 UI 검토 경로에서 제외합니다. 기본 JavaScript 검증은 입력을 유지합니다. |
| P1-A: 조건식 문법 | 허용한 `contains`, `in`, `length`, `not` 및 괄호 조건을 Python·JavaScript에서 해석·평가합니다. native export는 같은 분석 결과를 R 조건과 생성한 복수 응답 처리 함수로 변환합니다. 잘못된 조건은 규칙 이름과 지원 예를 표시합니다. 임의 코드는 실행하지 않습니다. |
| P1-B: 보이지 않는 경고 | CLI는 통과해도 경고를 보여주며, 수정 개수에는 차단 오류만 셉니다. 배포 검사를 구분하고 골든 예제의 미지원 footer·highlight 설정을 제거했습니다. |
| P1-C, P1-E: 계정·mock 혼동 | 시작 안내에서 직접 로그인·승인 필요성을 설명합니다. mock 화면에는 로컬 전용 안내를 표시하고 배포 단계 검사는 mock·미승인 상태를 차단합니다. 파일 완성이 실제 연결을 입증하지는 않습니다. |
| P1-F, P2-E: 가이드 로딩·마이그레이션 | core 전용 초기 검사로 연구 유형을 성급히 정하지 않습니다. 실제 연구 lock에는 유형이 필요합니다. 일곱 마이그레이션과 한 시점의 저장소 전체 사용을 안내하며 기존 연구는 승인한 업그레이드 전까지 lock을 유지합니다. |
| P2-A, P2-F: 언어·화면 | 한국어 단어 줄바꿈을 개선하고, 미리보기 조작 안내는 한국어·중국어 간체/번체·영어를 따릅니다. 연구자가 작성한 문항은 자동 번역하지 않습니다. |
| P2-C: 문서 제목 | 기존 참가자 템플릿은 이미 연구 제목과 언어를 적용합니다. 새 수정으로 포장하지 않고 회귀 시험으로 보존합니다. |
| P2-D: Python 경고 | 포맷팅 정규식을 raw 문자열로 변경했습니다. |

새 초안 생성·기록과 문서 누락·잘못된 경로·승인 취소·CLI·조건식 일치·실제 브라우저 슬라이더/후속 문항 및 기존 전체 시험으로 확인합니다. R이 있으면 생성한 native 코드의 문법도 확인하지만 surveydown의 전체 동작 동등성을 입증하는 것은 아닙니다. Claude 시험은 로그인에서 멈췄으므로 외부 배포 검증은 포함되지 않습니다.

Vercel의 새 선택적 기능은 [Vercel 에이전트 연결 준비](./vercel-agent-onboarding(kor).md)에서 별도로 검토했습니다. 이번 검토를 위해 전역 설치·인증·유료 모집·Vercel/Supabase 프로젝트 변경은 수행하지 않았습니다.

검증 완료: 버전 갱신 후 Python 187개와 Node/브라우저 41개 시험이 모두 통과했습니다(건너뛰기 없음). GitHub와 Google Sites에 반영했고 공개 홈페이지 전체 임베드가 생성 원본과 일치하는 것도 확인했습니다. AI와 함께 연구별 배정 절차를 설계하는 안내와 4개 그룹·그룹별 순차 텍스트 사례도 포함했습니다.
