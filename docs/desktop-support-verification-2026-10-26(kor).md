# 데스크톱 지원 정책 확인 기록

[English](./desktop-support-verification-2026-10-26.md)

프로젝트 소유자가 연구자의 설문 제작을 데스크톱 앱에서만 공식 지원하도록 정했습니다. 설치된 앱에서도 가이드 읽기·파일 생성·미리보기 실행을 실제 확인합니다. AI 웹 앱, PWA 바로가기, 도구 없는 채팅은 첨부 파일로 예외를 인정하지 않습니다. 참여자의 브라우저와 연구자의 미리보기·결과 화면은 계속 지원합니다. 이는 지원 정책이며 모든 제공업체 웹 앱의 기능 불가를 뜻하지 않습니다.

2026-10-26 로그인 없는 원문 START-HERE.md와 registry/guide-index.json 직접 확인은 HTTP 200이었습니다. 나중 제보의 정상 분리된 URL 접근 실패는 이전의 붙여넣기 주소 문제와 다릅니다. 스크린샷에 PERMISSION_DENIED라는 보고가 있지만 도구 실행 기록이나 정확한 원인은 드러나지 않습니다. 설문 제작을 멈춘 동작은 맞습니다. 해당 계정으로 Gemini 데스크톱의 전체 제작·배포 시험을 수행하지 않았습니다.

공식 다운로드 안내 전에 실제 문서를 열어 확인했습니다: [Gemini](https://gemini.google/desktop/), [ChatGPT](https://learn.chatgpt.com/docs/app), [Claude](https://claude.com/download). 제품 제공 여부가 greedyQ 전체 적합성 검증을 뜻하지는 않습니다. 홈페이지 HTML은 별도 게시 워크를 위해 준비하며 이 작업에서 Google Sites를 게시하지 않습니다.


추가 결정: Gemini는 데스크톱을 포함해 공식 지원에서 제외합니다. 당시 공유된 Gemini 대화 링크는 이 도구로 읽히지 않아 전체 원문을 검토하지 못했습니다. 이후 연구자가 제공한 8쪽 PDF를 아래와 같이 검토했습니다. 정책은 연구자의 제보와 제공된 화면을 근거로 하며 Gemini 내부 원인을 지어내지 않습니다. 공식 제작 경로는 파일·작업 도구를 확인한 ChatGPT 데스크톱 Work/Codex와 Claude Desktop입니다.


로컬 회귀 검사: Python 237개와 Node/브라우저 57개가 실패·생략 없이 통과했습니다. 복사 검사는 3개 언어·2개 너비의 270건이며 BibTeX를 보존합니다. CBC 표시 6개 조합의 Python·JavaScript 모델과 해시가 일치하고 320/390px의 세로·모바일 반응형은 페이지 좌우 스크롤이 없습니다. 표시 항목을 생략한 기존 설계 해시는 유지합니다. Gemini, 유료 CBC 연구, 아직 수행하지 않은 CBC 클라우드 배포를 검증했다는 뜻은 아닙니다.

## 이후 제공된 8쪽 PDF 검토

연구자가 제공한 Gemini 대화 8쪽을 모두 읽었습니다. 첫 추출·렌더링 도구가 한국어 글꼴을 제대로 처리하지 못해 macOS PDFKit으로 읽을 수 있는 텍스트를 복원하고 관련 페이지 화면을 확인했습니다. 원문 대화와 스크린샷은 개인 자료이며 공개 저장소에 복사하지 않습니다.

- 1쪽은 가이드 읽기 실패를 보고하고 연구 인터뷰를 멈춥니다. 적절한 동작입니다. 다만 대화 원문에 실제 도구 실행 기록은 없습니다.
- 2~5쪽은 제공업체 전체의 원문 도메인 차단, JavaScript 렌더링, API·CDN 제한, 크롤러 정책을 원인으로 단정합니다. 실제 테스트라고 표시한 표도 축약·일반형 URL만 있고 요청·응답 기록이 없습니다. 독립 검증된 원인이 아닌 모델의 설명으로 취급합니다. 우리가 원문 가이드와 파일 목록을 로그인 없이 확인한 HTTP 200은 우리 환경에서 공개 접근이 된다는 증거이며 Gemini 내부 도구의 접근을 입증하지는 않습니다.
- 6쪽은 Python 환경이 외부 네트워크와 완전히 차단되었다고 주장합니다. 이 대화만으로 제공업체 전체 정책이나 이번 가이드 실패의 정확한 원인을 입증할 수 없습니다.
- 7~8쪽은 ZIP 첨부, 프록시, 다른 개발 도구를 제안합니다. 실제 저장소 첨부, 가져오기 성공, 정해진 코드 빌드, 동작하는 미리보기, 연결된 배포는 PDF에서 시연되지 않았습니다. 앞으로 실행하겠다는 약속은 전체 과정의 검증 결과가 아닙니다. 제안들을 프록시 구현이나 미지원 환경의 설문 제작 재개 지시로 취급하지 않습니다.

정책은 유지합니다. Gemini는 데스크톱을 포함해 별도의 전체 과정 검증 전까지 공식 지원하지 않습니다. 공식 제작 경로는 필요한 파일·미리보기 도구를 확인한 ChatGPT 데스크톱 Work/Codex 또는 Claude Desktop입니다. 다른 제공업체의 내부 제한에 관한 미검증 주장을 안내에 옮기지 않습니다. 기능 확인, 가이드 접근 실패, 실제 실행 성공을 구분해 기록합니다.
