# 연결 규약과 연구자 안내서 업데이트

[English](./connection-and-guide-update-2026-10-25.md)

릴리스: `0.2_2026-10-25_f2afa11`.

## 변경 내용

- 기존 Vercel/Supabase 연구자 여정을 유지합니다. 계정·팀을 확인한 기존 공식 연결을 우선 활용하고 연결·기능이 없으면 지원되는 CLI/통합 경로를 유지합니다. Onboard your agent는 선택 사항입니다.
- 로그인은 성공해도 팀 목록이 비는 별도 팀 승인 사례를 반영했습니다. 계정을 재연결하거나 권한 거절을 몰래 우회하지 않고 해당 팀 승인 후 같은 연결에서 재시도합니다. 연결·조회 성공은 새 경로의 배포·저장 검증이 아닙니다.
- 간체 중국어 시작·사용자·AI 가이드 17종, 상호 언어 링크와 유지 규칙을 추가했습니다. 영어가 규약 원본이며 중국어 완전판도 같은 기준 코드를 그대로 포함합니다. 세 언어에 같은 버전을 적용합니다. 모든 개발 문서의 중국어 번역을 뜻하지는 않습니다.
- 홈페이지 한국어·영어·중국어 설명을 연구자의 행동 중심으로 풀어 썼습니다. 따옴표로 표시한 설문·결과·미리보기 용어를 설명하고 링크별 전달 대상, 연습과 실제 응답, 내려받기·보관 방법을 안내합니다. 갤러리와 이미지를 유지하고 코드 이름은 선택적으로 펼쳐 보게 했습니다.
- 작은 화면에서 상단 메뉴가 요청문 복사를 가리던 자동 부드러운 스크롤을 제거했습니다. 로컬 사용자 여정 시험에서는 참가자·관리자 데이터베이스 연결을 분리해 진행 중인 참가자 역할이 관리자 검사에 섞이지 않게 했습니다. 실제 연구 리소스는 변경하지 않습니다.
