# 골든 레퍼런스 설계: 온라인 강좌 구독

[English](./README.md)

**실행 가능한 로컬 미리보기 기준 예제이며 실제 연구나 승인된 표본은 아닙니다.** [단일 미리보기 파일](./cbc-preview.html)을 다운로드해 최신 브라우저에서 여세요. 독립적으로 작성한 가상 예제로 가져오기·화면 동작을 검증하며 통계 효율이나 검증된 척도를 의미하지 않습니다. [현재 안내](../../../../CBC(kor).md)를 참고하세요.

## 시나리오

가상의 온라인 강좌 구독을 비교합니다. 설명상 대상은 온라인 강좌를 아는 성인이지만 실제 참여 조건 문구·지역·언어·표본 수·동의·보관·보상·추정법은 연구자가 결정해야 합니다. 기관이나 윤리 승인을 지어내지 않습니다. 예제에는 개인정보나 민감한 특성이 필요하지 않습니다.

| 속성 | 수준 |
| --- | --- |
| 월 요금 | 월 GBP 10, GBP 20, GBP 30 |
| 강좌 형식 | 녹화 영상, 글로 된 수업, 온라인 실시간 수업 |
| 튜터 지원 | 지원 없음, 이메일, 실시간 채팅 |
| 구독 종료 후 접근 | 1개월, 3개월, 12개월 |

과제마다 모든 속성을 가진 무표지 대안 두 개와 “어느 요금제도 선택하지 않음”을 제시합니다. 블록 두 개에 각각 과제 네 개가 있어 전체 과제 정의는 여덟 개, 일반 프로파일은 열여섯 행입니다. 참여자는 동일한 배정 확률로 블록 하나를 받아 과제 네 개에 답하는 것으로 제안합니다. 과제 순서와 과제별 일반 대안 순서는 한 번 섞어 유지하며 none은 마지막입니다. 프로그램 예제를 위한 선택이며 통계 정밀도나 응답 부담에 대한 권고는 아닙니다.

## 제안하는 참여 흐름

1. 시작, 승인된 참여 안내와 동의.
2. 관련 강좌 경험 확인. 제외가 필요하면 별도로 검토한 종료 경로 사용.
3. 속성 네 가지·가격·none의 뜻 설명. 연구자가 확인하면 점수를 매기지 않는 연습 예시 제공.
4. 동의 뒤 블록 하나를 배정하고 기록된 순서를 유지하며 네 과제 표시.
5. 선택적인 사용 의견, 정상 완료 또는 자발적인 철회.
6. 보호된 결과 확인과 설계 버전을 포함한 실제 표시·선택 내보내기.

실제 외부 서비스 인증 정보나 완료 코드는 없습니다. 구현할 때 기존 direct·Prolific 기본 계약을 재사용해야 하며 새 보상이나 모집을 승인한 것이 아닙니다.

## 파일과 예상 데이터

- `study.design.json`: 제안한 결정, 명시적인 `fielding_approval=false`, 설계 단계 표식, 블록·순서·none 규칙과 미결정 추정법.
- `design/attributes.csv`: 수준 열두 행, 안정적인 ID와 표시 문구.
- `design/design.csv`: 블록·과제·대안으로 구분하는 일반 프로파일 열여섯 행.
- `design.manifest.json`: 원본 파일 hash와 예상 크기. 통계적 효율성은 확립하지 않았음.
- `expected/choice-data-long.csv`: 블록별 한 명씩 가상 참여자 두 명의 **가상** 데이터 스물네 행. 각 참여자는 네 과제에 과제당 세 대안을 가지며 정확히 하나를 선택합니다. none 행의 속성 칸은 비어 있습니다. 연결을 쉽게 확인하려고 원본 순서를 사용한 예상 예제이며 관측된 무작위 추출이나 실제 참여자 자료가 아닙니다.
- `expected/scenarios.json`: 앞으로의 승인 시험 계획과 명시적인 구현 공백.
- `survey.qmd.draft`: 제안하는 작성 예시이며 v0.2에서 허용되는 파일이 아님.

빈 CSV 두 개와 Excel 파일은 [templates](../templates/README(kor).md)에 있습니다. 초안 검사기는 구조·코드 참조·hash·가상 선택 행 연결을 확인하며 설계 생성이나 선호 추정을 수행하지 않습니다.

## 앞으로 반드시 시험할 상황

두 블록, AI 도움·연구자 직접 표 작성, 대화 저장→다운로드→다른 호스트에 반환, 잘못된·부분·중복 행, 여러 언어와 문자열 ID, 확인한 금지 조합, 새 세션·재접속의 과제·대안 순서, 키보드·모바일 선택, none과 미응답 구분, 이전·새로고침, 저장 중단·재시도, 동시 제출, 동의 거부, 철회 시 선택·표시 삭제, 실제·시험 분리, 보호된 결과·긴 CSV, 설계 수정 시 새 버전, 응답을 복사하지 않는 fork, native export 한계의 명시입니다.

표본 수나 분석 모형을 자동 확정하지 않습니다. 앞으로의 사전등록 초안에는 승인된 선택 설계·블록 배정·순서·제외·결측 처리·추정 대상·분석과 함께 미결정을 눈에 띄게 남겨야 합니다.

## 다음 구현 관문

Python 기준 가져오기와 같은 계약의 고정 브라우저 가져오기·화면을 구현하고 시험했습니다. 전용 수집 계약도 로컬에서 검증했습니다. 다음은 클라우드 승인 시험·QMD 혼합·네이티브 CBC 내보내기입니다. 로컬 미리보기만으로 실제 모집 가능한 연구라고 설명하지 않습니다.


가져오기·화면 구현은 Python/브라우저 자동 테스트로 검증합니다. 별도 수집 흐름에 서버 저장·실제/시험 분리·동의·철회·보호된 결과/CSV를 구현했습니다. 단일 미리보기는 로컬용이며 실제 클라우드 CBC 승인 시험은 남아 있습니다.


`preview.manifest.json`에 현재 미리보기·모델의 출처와 파일 해시를 별도로 기록했습니다. 이전 `design.manifest.json`과 예상 CSV는 기획 기준 자료로 유지합니다. 그 해시는 정규화된 미리보기 모델이 아닌 이전 초안 구조를 나타냅니다.


별도의 [수집 흐름](../../../../CBC-COLLECT(kor).md)에 서버 저장·동의·철회·보호된 결과·보관 내보내기를 추가했습니다. `collection.test.example.json`은 승인 항목이 모두 false인 명백한 가상 Test 설정이며 승인된 참여자 연구가 아닙니다. 로컬 전체 흐름 검증과 클라우드·유료 CBC 검증은 구분합니다.
