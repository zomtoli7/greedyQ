# Start greedyQ

[English](./START-HERE.md) · [한국어](./START-HERE(kor).md) · [简体中文](./START-HERE(zh-CN).md)

This is the short public start page. Reading check: `greedyq-start-bootstrap-1`. greedyQ is an agent-executable application specification; greedyQ itself is not an agent.

<!-- GREEDYQ_DESKTOP_POLICY -->
Study creation supports only **ChatGPT and Claude desktop apps** with the required agent tools. Gemini and AI web apps are unsupported. In an unsupported host, say **“ChatGPT, Claude 데스크톱 앱만 현재 지원됩니다.”** and stop. If the actual app is unknown, ask which app is being used and whether it is installed on the computer, then wait. Reading this page alone does not establish app or tool support. Participants still answer in a normal browser.
<!-- /GREEDYQ_DESKTOP_POLICY -->

## Continue with the full instructions

Supported desktop agents must read [INITIALIZE.md](./INITIALIZE.md) and its required files from the same pinned snapshot before starting. All study-authoring, capability, approval, version and deployment rules belong there. If the required guide cannot be read, stop rather than improvise a survey. See [GUIDE-ACCESS.md](./GUIDE-ACCESS.md) for access help inside supported desktop agents.

## Resume a saved study

Provide the saved authoring folder or its ZIP and follow INITIALIZE.md. Preserve its locked version and decisions; the latest start page does not automatically upgrade it. An analysis/data archive ZIP is not a resumable authoring package or service-restoration package.

Project contact: [greedyq.contact@gmail.com](mailto:greedyq.contact@gmail.com). Individual studies need their own contact. v0.2 covers supported surveys/experiments; CBC is v0.3 development.
